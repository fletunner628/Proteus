## ⚡ Key Features
<a id="key-features"></a>
### Core Functionality
- **ISIS (Intelligent Schematic Input System):** Create electric designs with a variety of components, including resistors, coils, capacitors, and microprocessors.
- **ARES (Advanced Routing and Editing Software):** Design printed circuit boards (PCBs) with routing, location, and editing tools.
- **Extensive Library:** Access to nearly 800 different microprocessors for realistic circuit simulations.
- **Real-time Simulation:** Simulate integrated circuits and their features dynamically.
- **Arduino Integration:** Design and simulate directly within the Arduino environment.

### Advanced Features
- **Diff Pair Configurator:** New tools for advanced circuit design.
- **Align and Distribute Commands:** Enhanced control for component arrangement.
- **New Manufacturing Rules:** Updated features for PCB design.
- **Self-routing Module:** Automate the routing process for optimal circuit performance.
